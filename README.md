# SodeX Studio

Dark crimson portfolio for a fullstack developer: WebGL atmosphere, horizontal scroll projects, animated tech stack and direct contact links.

## Live Site

[Open SodeX Studio](https://sodex00.github.io/SodeX-Studio/)

## About

SodeX Studio is a personal portfolio focused on fullstack work:

- frontend interfaces with React and TypeScript
- backend APIs and database-driven products
- Telegram and Discord bots
- Telegram Mini Apps
- iOS and Android app experiences
- 3D/WebGL visual presentation

## Stack

- React
- TypeScript
- Vite
- Three.js / WebGL
- Lucide Icons
- CSS animations
- GitHub Pages

## Features

- interactive Three.js background
- dark red visual style
- pinned horizontal project showcase
- animated moving technology strip
- responsive layout for desktop and mobile
- clickable Telegram, email and GitHub contacts

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

```bash
npm run deploy
```
